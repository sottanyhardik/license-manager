# Reconciliation and parity plan

Compare old and new systems using approved golden cases and an isolated data copy. Each comparison records scope/filter/date/company, source records, formula/rule version, result, tolerance, difference, disposition and reviewer.

Required parity: licence balances/usage, restriction pool/AU decisions, BOE/invoice/allotment links, reports/API/Excel/PDF totals, documents, company access denials and eventual accounting journals/subledgers. A difference is permitted only for an approved defect correction with a migration/communication plan.
