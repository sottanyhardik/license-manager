# Business-rule preservation and decision catalogue

## Classification policy

- **Verified and preserve:** direct code plus execution/golden-data evidence.
- **Business confirmation required:** existing behaviour found but intended meaning is not established.
- **Approved defect correction:** documented legacy difference with owner approval.
- **New:** no legacy compatibility claim.
- **Not assessed:** access/evidence insufficient.
