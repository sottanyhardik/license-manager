# Q4 read/report/workspace individual operation packets

This packet set covers the exact Q4 population in
[the API closure queue](api-contract-closure-queue.md): **25 operations**
tagged `active-licenses`, `expiring-licenses`, `reports`,
`inventory-balance`, `item-pivot`, `item-report`, `planned-report`,
`dashboard`, or `import-item-suggestion`. Each `API-*` appears once. It is
source/test characterisation, not a completion claim: all rows remain
**Partial** until their direct DTO, role/object result, UI state and recovery
evidence meets the [closure protocol](contract-closure-protocol.md).

`C` is current-code evidence, `R` is current OpenAPI/runtime registration,
`T` is a named current test group, `I` is a static consumer and `D` marks a
decision dependency. Read role access is not company/object isolation (D1).
Report balance/provenance labels require D2; generated file/token policy
requires D4; accounting labels require D5.
