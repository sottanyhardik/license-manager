# Implementation roadmap

1. **Evidence foundation:** restore source index, record deployed baseline, establish isolated test/restore environment and decisions.
2. **Database/rule contracts:** migration mapping, canonical balance lifecycle, restriction/AU corpus and golden examples.
3. **Platform security:** company membership, scoped authorization, audit events, CI and test data.
4. **Operational core:** ledger, restrictions, allocation, BOE/trade/document correction and reconciliation read models.
5. **Compatibility UI/reporting:** rebuild approved routes/work queues and canonical exports.
6. **Accounting:** CA-approved journal/subledger/bank/period work after operational parity.
7. **Migration/release:** dry runs, reconciliation, full regression/security/recovery, staging UAT and approved cutover.

The task register is the only active delivery breakdown. No task is complete until its evidence and review requirements pass.
