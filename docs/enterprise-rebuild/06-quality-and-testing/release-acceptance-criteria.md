# Release acceptance criteria

- No unexplained material migration, licence-balance, restriction or accounting discrepancy.
- Required tests, type checking, linting and migration checks pass; approved exceptions are explicit.
- No unresolved critical/high security release blocker; company isolation proven server-side.
- All required route/API/workflow compatibility cards have evidence.
- Backup restore and rollback/delta recovery rehearsal succeed in isolation.
- Owner/domain/CA acceptance is captured for their decisions.
- Production approval identifies version, scope, monitoring, rollback owner and post-release checks.
