# UI/UX and workflow assessment

Live navigation has Dashboard, Licences, Operations, Reports and Masters. Improvements should reduce checking work, not merely restyle pages.

- Dashboard: actionable ownership, age, materiality, drill-down and next action for missing DGFT, expiry, matching, duplicate candidates, failed imports and rule issues.
- Lists: visible default/active filters, saved views, clear reset, compact finance table option, consistent labels/units/currency/date and export scope parity.
- Planning: validation drill-down, rule source/version/effective date/audit history, simulation, explanation and safe high-impact actions.
- BOE/reconciliation: dependency/financial-impact preview, reason and confirmation for merge/delete/reversal, candidate evidence and dry-run bulk actions.
- Shared design: keyboard, responsive tables, loading/empty/error/success states, accessible field errors and Axe tests.
