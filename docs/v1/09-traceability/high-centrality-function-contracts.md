# High-centrality function contracts

This bounded register traces the most widely imported backend interfaces and
the functions that concentrate balance, authorization, master-data, sync,
projection, and durable-job behaviour. It is intentionally **not** a claim
that their static importers call a particular symbol: a file dependent is
blast-radius evidence only. Likewise, named tests are evidence that a test was
located, not proof of all branches or public API contracts.

Evidence labels: **C** = verified by inspected code; **S** = static index or
file-dependent evidence; **T** = named existing test evidence; **P** = V1
proposal; **D** = owner decision required. Each contract is **Partial** until
its direct callers, authorization/object scope, failure behaviour, and
regression coverage are closed.

## Closure rules

A row can become **Verified** only when the audit attaches direct caller(s),
the concrete data/transaction effect, applicable endpoint or task
authorization (including the approved D1 scope where relevant), representative
negative and recovery tests, and a named acceptance criterion. This register
therefore advances evidence for 16 high-centrality contracts while leaving the
whole 8,046-symbol register explicitly **Partial**.
