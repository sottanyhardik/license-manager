# Option B - Core License Manager with integrated accounting

Option B includes all Option A scope and adds company-wise accounting: tenant/legal entity boundary, chart, periods/opening balances, immutable journals/vouchers, source-document posting, AR/AP, receipts/payments/advances, cash/bank, trial balance/GL/day/cash/bank books, financial statements, bank reconciliation, controlled migration and optional CA-approved tax/Tally work.

It does not assume operational invoices are accounting invoices. A source-document bridge with idempotency key prevents double posting. Accounting starts only after Option A canonical values/company isolation are accepted.
