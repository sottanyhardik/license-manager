## Cross-cutting evidence and V1 acceptance order

1. Reconcile the three source-visible report paths absent from the current
   OpenAPI operation map before treating a frontend request as a contract.
2. For every admin/master mutation, direct backend role/object tests must
   precede any conclusion based on `ProtectedRoute`, hidden controls or client
   redirects; D1 governs company/object scope.
3. Preserve authenticated blob fetching for reports/downloads until D4 is
   approved. Add browser failure feedback and content/provenance assertions,
   not only mocked filename tests.
4. Repair the documented Playwright harness/fixture failures, then execute
   L/E/S/D (loading, empty, success, denied) state tests against these routes.

This adds a bounded **10 surfaces / 13 route-ID** source trace. It changes no
global route/API completion metric: all frontend routes remain Partial until
their UI, server, authorization and browser evidence are reconciled.
