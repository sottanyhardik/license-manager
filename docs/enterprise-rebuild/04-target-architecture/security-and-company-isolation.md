# Security and company isolation

Static evidence shows authentication, roles and protected media foundations, but does not demonstrate complete server-side company scoping. The rebuild must introduce a membership/ownership policy and mandate scope at queryset, object, write, bulk action, report/export, file and background-job boundaries.

Required proof: role/company test matrix; manipulated identifier/filter/export tests; task-context tests; audit events for material operations; safe session/error/log/file handling; no security claim based solely on hidden UI controls.
