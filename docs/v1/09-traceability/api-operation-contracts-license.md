# Individual licence, allotment, BOE, planning and ledger operation contracts

## Scope and evidence rule

This register advances **113 exact OpenAPI operations** used by the P0/P1 licence, allotment, BOE, planning, report/upload and ledger workflows. It is an overlay to the generated [API operation register](api-operation-register.tsv), not a replacement for it.

Every appendix row below has a verified OpenAPI method/path, resolved callback source/action and declared permission/schema/response metadata. Its family section provides directly source-inspected service/data/transaction/test evidence. A row remains **Partial** unless a direct request/response fixture, action-level negative authorization, object/company-scope result, consumer linkage, and error/recovery test are recorded. “No OpenAPI request schema declared” must never be read as “no request body”.

The family evidence is **verified by code/test discovery** through the action and workflow maps. It deliberately does not make every listed callback individually complete.
