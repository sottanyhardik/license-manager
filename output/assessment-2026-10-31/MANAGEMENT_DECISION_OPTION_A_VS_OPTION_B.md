# Management decision - Option A versus Option B

| Dimension | Option A: core operational | Option B: core plus accounting |
|---|---|---|
| Licence/DFIA/BOE/invoice/reconciliation | Included | Included |
| Data remediation/security/UI | Included | Included |
| GL, AR/AP, expenses, bank, statements | Excluded | Included |
| Likely effort | 445 days | 775 days core; 905 with advanced accounting |
| Value timing | Earlier | Later, after foundation/cutover |
| Risk/maintenance | Lower, operational focus | Higher: policy, migration, tax and financial control |
| Best fit | 1-2 staff using external accountant/Tally | Owner needs in-app cash/receivable/payable/bank control and CA support |

**Recommendation:** Option A first, architected with company context and stable source-document references so Option B can follow. Choose B now only where current external-accounting dependency materially blocks daily control and the owner funds a CA-led chart/opening/cutover programme.
