This is a bounded direct-source audit of **14 document ingestion, generation,
storage and delivery boundaries**. `C` is current code evidence, `T` is a
narrow named test, `S` is static dependency evidence, and `P` is a V1
proposal. It does not certify malware scanning, production object storage,
nginx configuration, retention, or every upload caller. Every contract is
**Partial**.

## V1 guardrails

1. Do not turn parser prefill into an implied durable business transaction:
   parse-side reference creation and eventual master-save recovery require
   explicit acceptance tests.
2. Preserve protected-media realpath and record-linked RBAC boundaries, but
   do not call them tenant isolation until D1 approves the object/company
   policy.
3. Treat all document byte validation as incomplete unless a concrete policy,
   scanner/infrastructure proof and failure cleanup test exist. None is
   inferred from extension checking or a parser exception.
4. Keep export/PDF/Excel rendering sourced from named ledger/balance engines;
   label Customs/Financial outputs pending D2 and exercise delivery failure in
   browser and storage-like environments.
5. Transfer-letter and ledger-package output must have an explicit
   concurrency, temporary-artifact and recovery specification before their
   implementation is modernized.

This register adds 14 bounded contracts. It does not alter the 354 API,
57-route or 8,046-symbol complete-contract denominators.
