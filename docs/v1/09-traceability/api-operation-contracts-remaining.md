# Remaining individual API operation contracts

## Scope and evidence rule

This register supplies the **99 operations** not covered by the two preceding individual-contract registers: [identity/master/sync/task](api-operation-contracts-auth-masters.md) (142) and [licence/allotment/BOE/planning/ledger](api-operation-contracts-license.md) (113). The three sets are disjoint and total **354/354 registered OpenAPI operations**.

Each annex row is grounded in the validated OpenAPI operation metadata and its resolved callback source/action: method/path, declared request schema, documented success response, callback permission class and source file. `None declared` describes OpenAPI only; it does not prove that a body, query field or error status is absent.

Every row remains **Partial**. A complete individual contract requires direct evidence for DTO validation, action-level authorization and object/company scope, mutation/transaction effects, frontend or external consumer, error/recovery behavior and a focused regression test. Family evidence below helps locate that proof; it does not close every member operation.
