# Q2 planning and licence-mutation individual operation packets

**Population: 33 registered Q2 operations.** This document has one row for
every operation tagged `license-actions` (API-075–079),
`license-item-plans` (API-080–087), `license-items` (API-088–091), or
`sion-planning-rules` (API-299–314) in
[the operation register](api-operation-register.tsv). It is direct source and
selected-test evidence, not a completed contract. Every row remains
**Partial**: the D1 object/company policy, D2 balance semantics, D3 pool/rule
policy and D6 audit-durability requirements remain unapproved where relevant.

`C` is current-code evidence; `S` is OpenAPI/register evidence; `T` is named
current test evidence; `I` is known static UI/consumer evidence. A shared
`LicensePermission` role gate is not an object/company authorization result.
