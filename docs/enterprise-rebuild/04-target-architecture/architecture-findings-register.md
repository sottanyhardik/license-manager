## Audit limits and unresolved evidence

- The final index covers 1,545 tracked files, 9,867 symbols and 2,932 resolved
  static internal edges in each direction. It does not establish runtime call
  paths, dynamic registrations, ORM query scope, task execution, template use
  or deployed data behavior.
- No production database, production configuration, tenant data, accounting
  policy or authoritative balance lifecycle was accessed. Findings requiring
  those facts remain blocked rather than inferred as defects.
- Existing database findings DB-001 through DB-005 remain authoritative for
  live-schema and deletion-policy questions; this register adds current source
  evidence, not a replacement audit.
