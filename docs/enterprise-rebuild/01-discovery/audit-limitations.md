# Access and audit limitations

| Limitation | Consequence | Required evidence / owner |
|---|---|---|
| `.Codex/index/` unavailable | Exact source-symbol and caller inventory cannot yet be asserted | Restore/rebuild index or approve alternate inventory process |
| Production deployment unknown | Local `develop` behaviour cannot prove production behaviour | DevOps read-only version/config evidence |
| No authorised production DB inspection | Display metrics cannot be reconciled to records | Read-only query access or isolated restored copy |
| No restore rehearsal | Backup existence cannot prove recovery | Isolated restore test evidence |
| Dynamic/mutating flows not exercised | Save/post/import/delete behaviour remains partially unverified | Isolated test/staging environment |
| Restriction sources not approved | AU and percentage semantics cannot be treated as legal rules | Owner/domain adviser supplies official source corpus |
| Accounting policy unavailable | Opening/cutover/tax/statutory design cannot be final | CA-approved accounting decision pack |
