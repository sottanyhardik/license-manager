# High-risk entity lifecycle contracts

**Bounded source audit — 12 entity families.** This register records model and
migration-source evidence for financial and entitlement-critical records. It is
not a live-database introspection: it does not prove that a deployed database
has every stated constraint/index, that migrations have been applied, that
historical data satisfies those rules, or that backup/restore preserves every
relationship. Every record remains **Partial** until those additional checks
are completed.

Evidence labels: **C** = verified by current model/migration code; **T** =
named existing test evidence; **P** = proposed V1 action; **D** = owner-policy
dependency. The relevant overall limitation is recorded in [current schema](current-schema.md)
and [data integrity](data-integrity.md).

## Migration and operational implications

1. **Additive first.** Historical migrations contain data backfills, merge
   migrations and repair operations across licence, allotment and BOE domains.
   A V1 schema change must name its exact predecessor, affected representation,
   forward validation query and forward-recovery path; source-level field
   presence is not sufficient migration evidence.
2. **Do not collapse representations.** Stored availability/balance snapshots,
   plan legacy fields, header compatibility properties and ledger allocation
   rows have deliberately different authority/lifecycle statements in source.
   D2 and D3 must be decided before consolidating or deleting any of them.
3. **Deletion needs graph tests.** `CASCADE`, `PROTECT`, `SET_NULL` and M2M
   relationships above create materially different correction/deletion paths.
   The required live-schema audit must inspect foreign-key actions, partial
   indexes and constraints after migrations, not merely model declarations.
4. **Backups/recovery remain unproven.** Before a migration, take an isolated
   restore, run integrity and aggregate reconciliation checks, exercise worker
   request recovery, and retain a forward-only repair plan. No production/local
   data inspection or migration has been performed by this documentation audit.
