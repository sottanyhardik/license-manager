## Verified distinctions and V1 guardrails

BAC-01, BAC-02 and BAC-04 are distinct values by code: the first excludes
hidden BOEs, the second includes them, and the third follows financial trade
and allocation treatment. Any consolidation, rename or report substitution
requires D2 and golden output comparisons. Allocation capacity is enforced at
BAC-09, not by a frontend candidate list or advisory service result; a V1 API
split must preserve its locked read-check-write boundary and post-commit
replan path.

**P:** Each P0 contract needs anonymous, wrong-role, approved-role,
D1-approved cross-company/object, stale-data, decimal-boundary, rollback and
background-dispatch tests. This adds **17 bounded contracts** only; all other
symbols remain Partial.
