Every row is **Partial**. A source line, schema declaration, selected existing test, or static UI consumer does not provide the full closure packet: direct DTO/response fixtures, effective action authorization and D1 scope, consumer state, negative/recovery proof, and owner approvals D1/D2/D4/D6 remain required.

Evidence labels: **C** = current code; **R** = OpenAPI/runtime register; **T** = named current test family; **S** = static consumer; **D** = owner decision. The common ledger role gate is `LicenseLedgerViewPermission`; it is role-based, and owner-scopes durable jobs but does not prove company/object policy (D1). Licence CRUD/actions use `LicensePermission`; manager-only mutations are not an approved company policy.

## Measurement and handoff

All **66/66** Q3 operation IDs now have a distinct row. The rows reuse selected existing ledger/package, balance, planning, PDF/export, parser and upload test evidence without treating a test family as full action coverage. **0/66** is promoted to `Verified`: D1/D2/D4/D6, direct fixtures, effective action authorization/object scope, file/storage/worker recovery and browser state proof remain required. This document is an individual-operation map, not authorization to consolidate balance engines, change downloads, or refactor package/upload behavior.
