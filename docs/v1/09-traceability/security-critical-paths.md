# Security-critical path contracts

This is a bounded, evidence-backed audit of authentication, direct document
access and capability-style invoice links. It is not a certification, a full
endpoint authorization matrix, or evidence of a company tenancy policy.

Evidence labels: **C** = verified by inspected code; **T** = existing test
evidence; **S** = static/configuration evidence; **P** = V1 proposal; **D** =
owner decision required. All rows remain **Partial**: a role gate does not by
itself establish object or company isolation.

## Bounded population

| Area | Contract IDs | Why selected | Explicit exclusion |
| --- | --- | --- | --- |
| Browser/API credentials | SCP-01–03 | JWT transport can authorize every registered API operation. | Does not prove CORS, proxy header or deployed-cookie configuration. |
| Uploaded/generated documents | SCP-04–05 | Documents contain customs, invoice and company information and are reached outside normal CRUD screens. | Does not inventory every storage object or prove deployed nginx configuration. |
| Invoice bearer capability | SCP-06 | A public `AllowAny` route intentionally relies on an opaque URL rather than the SPA header. | Does not prove email/PDF recipient handling or retention policy. |
| Company/object visibility | SCP-07 | Role code and tests explicitly allow cross-company reads for authorized roles. | No tenancy rule is inferred; D1 remains required. |

## Required implementation sequence

1. Obtain D1 and D4. They determine whether the current role-wide visibility
   and browser/capability credential trade-offs are intended.
2. Validate the deployed reverse-proxy configuration before relying on the
   protected-media code path; do not edit or reload it during this audit.
3. Add P0 direct-API negative authorization fixtures for reconciliation and
   balance mutations, then add approved object/company cases.
4. Convert the bounded tests above into CI gates, including production-like
   X-Accel and public-media absence checks where an isolated test environment
   can safely provide nginx.

## Traceability limits

This document closes no global denominator. It adds seven security-critical
contracts to the evidence set while retaining the baseline claims that all
354 API operations, 57 frontend routes and 8,046 backend static symbols need
broader per-contract completion work. Related source-contract rows are
[API-269](api-operation-contracts-auth-masters.md), API-317 in that same
register, and the trade entries in
